### ⚠️ 현재 한계점

#### 1. **OCR 정확도**
- 뉴스 이미지의 경우 OCR 오류 여전히 존재
- 예: "경향신문" → "겸량선문은", "윤관 → "윤품인"
- **해결 방법**: 이미지 전처리를 활성화하면 OCR 정확도 향상 가능

#### 2. **동일 문서 비교의 한계**
- 두 테스트 모두 동일한 원본 이미지 사용
- OCR 결과가 동일하면 후속 처리 결과도 유사
- **권장**: 전처리 ON/OFF 비교가 더 의미 있음

#### 3. **Java 의존성 (Konlpy)**
- 형태소 분석을 위해 Java JDK 필수
- Java 미설치 시 기존 방식으로 폴백
- **해결**: JDK 21 설치 권장
